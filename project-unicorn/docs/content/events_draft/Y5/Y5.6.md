--- INTENT ---

Each line is Frank's verdict on the run, the only place in the arc where a verdict is allowed out loud. It changes nothing (the run is over); its reader is the ending screen itself. Each line carries one fact of the run the player already knows (the signed terms, the four points Frank holds, the seven days, the calendar) and one turn in Frank's mouth. The Series A pair reads the signed terms the ending already knows (founder-friendly vs aggressive, the same fork the newspaper uses for END_SA_HEAD_FF / END_SA_HEAD_AGG), so no new memory is needed. Every line is three sentences or fewer, none over ten words. In bankruptcy and running_on_fumes the sealed pair closes the line, so "last sentence shortest" yields to the seal there.

Notes for the director: the engine fact stands: Frank's ending lines have no surface today; the rebuild either adds a Frank strip to EndingScene (reading `ending_data.frank_line`) or fires a pre-terminal Frank beat.
