Erdem 2026-10-23: target audience is white-collar workers who may not play games (virality via Twitter/LinkedIn), so the first release must run on **Windows and Mac**. Linux and Steam Deck are later ("illaki Steam Deck'e de getirmek isteyebiliriz ilerleyen süreçte").

**Why:** audience choice; Mac share among white-collar is high.
**How to apply:** platform risks are weighed for Windows+Mac first (Mac export, signing, Metal/Apple Silicon performance of the 3D office still unresearched). OS-dependent glyph fallback is avoided by bundling fonts (Noto Sans Symbols 2 into the dark chain, given to UI session for U3).
