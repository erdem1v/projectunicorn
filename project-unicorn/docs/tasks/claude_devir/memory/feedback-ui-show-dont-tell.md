On D's M2 sprint mockup Erdem said the system design is fine but the UI makes him queasy: the fonts look ugly on a dense screen, hierarchy is weak, and explanatory sentence lines ("Yeterli: fatura kesme çalışıyor, tahsilat takibi zayıf", "test yetişmiyor", "PM olmalı") are what make a game feel like AI slop. "Her şeyi oyuncunun gözüne sokmamalıyız."

**Why:** He wants the player to infer bottlenecks from visual form (work size vs team size), not be told; texty explanations read as generated.

**How to apply:** In any UI work: state through bars, icons, portraits, color, fill; explanations only in hover tooltips; people as icons not abbreviations; suggestions in game units (SP) not card lists; deadlines in player time ("bu çeyrek sonu") not sprint numbers; no unexplained labels ("öncelikli"); show what a manager/PM actually changed. Typography is open for a redo (Menajer fonts of 2026-10-02 questioned). Related: [[ui-redesign-menajer-2026-10-02]], [[feedback-design-research-first]], [[project-ai-production-decision]].
