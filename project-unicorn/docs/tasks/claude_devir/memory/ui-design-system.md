Project Unicorn UI design system, installed in the "design-language pass" (2026-07-01). Target visual identity = Erdem's "Shiftkod" Claude-Design prototype: **light warm-cream editorial body + dark charcoal chrome**, single amber accent, semantic badge colors, serif/mono/sans typography.

**Single source of truth = `scripts/theme/ui_tokens.gd`** (`class_name UiTokens extends RefCounted`, not an autoload). Holds the light palette, sizes, `TABS` (now incl. `icon` SVG paths), and static color helpers: `delta_color`/`delta_color_bright`, `badge_palette(kind)`, `badge_palette_for_delta`, `health_color`, `relationship_palette`, `bug_severity`. **Context rule:** text/state colors split by surface — `INK*` + `POSITIVE/NEGATIVE` on the light body; `CREAM*` + `POSITIVE_BRIGHT/NEGATIVE_BRIGHT` on the dark top-bar/ticker chrome. Legacy names kept as aliases (`TEXT_PRIMARY=INK`, `BG_VIEWPORT=BG_BODY`, …) so old refs work.

**`themes/master_theme.tres` is GENERATED, never hand-edited.** `scripts/theme/build_theme.gd` (`extends SceneTree`) builds it from UiTokens. Regenerate after any token/font change:
`& "C:\Users\erdem\Desktop\Godot_v4.6.2-stable_win64_console.exe" --headless --path "<proj>" -s res://scripts/theme/build_theme.gd`
(The `[MCP Runtime] port 7777` error in that headless run is benign — it still writes the theme, exit 0.) build_theme.gd is also the one place mapping physical fonts → serif/sans/mono roles.

**Applied project-wide** via `project.godot [gui] theme/custom`. Only `default_font` (IBM Plex Sans) is universal; everything else is **opt-in `theme_type_variation`** (inert until a node sets it), so out-of-scope screens only got a font refresh. Variations cover labels (TitleSerif, NameSerif, BodySerif, QuoteSerif, SectionLabel, MetricCaption/Value/Delta, BadgeLabel, ChoiceLabel, RowName/RowMeta, AvatarInitial, Chrome*), panels (TopBarPanel, SidePanel, NewsPanel, ViewportPanel, ModalPanel, ArtPanel, CardPanel/Tight/Attention, ChoiceCard, HeaderBand, Avatar, TabBadge, PhaseDot*, SelectedBorder, CapBar), buttons (TabButton(+Active), SpeedButton(+Active), CommitButton), RichTextLabel (BodyRich, NewsRich), BuildProgress.

**Runtime widgets** built via `scripts/theme/ui_factory.gd` (`class_name UiFactory`, all static): `make_badge/make_delta_badge/make_pill`, `make_choice_card`, `make_metric_cell`, `make_section_header`, `make_label`, `make_card`, `make_dot`. **Active/idle state = swap `theme_type_variation`** (e.g. TabButton⇄TabButtonActive), NOT captured sibling styleboxes (the old fragile pattern was removed from top_bar/left_tabs).

**Fonts:** `assets/fonts/{serif/SourceSerif4-*, sans/IBMPlexSans-*, mono/JetBrainsMono-Regular, fallback/NotoSansSymbols2-Regular}` (SIL OFL, full Turkish). Each role is a `FontVariation` `.tres` in `assets/fonts/variations/` carrying `fallbacks=[NotoSansSymbols2]` (setting a custom default_font drops Godot's built-in glyph coverage). **Tab icons = SVGs** in `assets/icons/tabs/*.svg`, white, tinted via `TextureRect.modulate`. Complexity/health dots are colored `●` glyph labels / `make_dot`.

**Styled (6 screens):** TopBar, LeftTabs, RightPanel, NewsTicker, EventModal, ProductTab (+GameShell frame). EventModal showcases it best (amber HeaderBand + dark ArtPanel + avatar/trait-chip character strip + drop-cap BodyRich + tinted effect badges via UiFactory). **NOT styled** (dark, font-only until a future pass): onboarding steps, PitchDialogueModal, SalesTab, MentorIntroModal, BuildHUDPanel — known light/dark seam. No mechanics or fake data were added (stubbed Rivals/Upcoming/cap-table-investors stay hidden/placeholder).
