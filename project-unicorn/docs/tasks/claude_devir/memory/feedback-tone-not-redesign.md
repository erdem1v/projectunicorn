When Erdem asks to bring other screens "in this line / this tone" after approving a redesign of one screen, he means a reskin only: font, icon style, color tokens, portraits. Layout, information structure, flows and content of those screens must stay exactly as in the current game.

**Why:** 2026-10-23 I briefed six mockups (Satış, Ekip, Finans, Kişisel, Gelen kutusu, Ar-Ge) as "reinterpret in the sprint-screen line"; agents redesigned whole screens. Erdem was furious: "Diğer ekranlarda problem yoktu ki, niye bozdunuz? Ben sadece bu tona dönsün dedim… Size değiştirin diyen oldu mu?"

**How to apply:** Scope = only what he explicitly asked to change. For a reskin, start from real current-game screenshots, reproduce layout 1:1, change only tone tokens, and show before/after pairs so he can verify nothing else moved. If a brief verb is ambiguous (yorumla / bu çizgide), pick the narrowest reading.
