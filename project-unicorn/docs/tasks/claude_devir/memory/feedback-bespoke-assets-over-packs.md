Erdem, asset laboratuvarının (render + asset lab task, [[render-assetlab-task-2026-10-09]]) yan yana karelerine
bakınca: "paketteki asetleri beğenmedim; bizim oyundaki mevcut asetler daha güzel ve daha niş, oradakiler jenerik."
Ofis geometrisi tasarımın kendi dışa aktarım hattında (`tools/office3d`) kalır; paket ailesi önerisi (Kenney + B)
kapandı. Laboratuvar (`sandbox/asset_lab/`, `1e2d9a0`) commit'li kalır, ama yeni bir paket geçişi önerilmez.

**Why:** Oyunun görsel kimliği tasarımın elle kurulmuş, düz renkli, ink'li dilinde; paket parçaları (pembe Kenney
mobilyası, modern komşu bloklar, nane ağaçlar) bu kimliği genelleştiriyor.

**How to apply:** Görsel iyileştirme önerileri mevcut asetleri koruyan teknik taraftan gelir (çözünürlük, AA, gölge,
ışık, ink); "hazır paketle değiştir" önerisi yalnız Erdem isterse.
